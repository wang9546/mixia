# 云函数模块 (Cloud Functions)

## 模块简介
本项目使用微信小程序云开发（CloudBase）提供后端服务。此目录下包含了所有为小程序提供数据接口的云函数。

## 函数列表与说明

- **`getHomeData`**: 首页聚合接口。用于一次性获取首页所需的 Banner 轮播图和各模块的精选推荐列表。
- **`getModuleList`**: 通用列表接口。用于获取“婚纱摄影”、“现场布置”、“婚车租赁”、“四大金刚”等模块的分页列表数据。
- **`getModuleDetail`**: 通用详情接口。通过传入模块类型和具体 ID，获取该案例或服务的详细图文信息。
- **`getStoreInfo`**: 获取门店配置信息。包括门店地址、联系电话、客服二维码等全局通用数据。
- **`getTags`**: 获取分类标签。用于列表页的筛选条件（如婚纱的风格标签、婚车的品牌标签等）。
- **`initDatabase`**: 数据库初始化脚本。在项目首次部署时使用，用于自动创建云数据库集合并注入演示用初始数据。

## 部署说明
每次修改云函数后，请在微信开发者工具中右键点击对应的云函数目录，选择 **“上传并部署：云端安装依赖（不上传node_modules）”** 以更新至云端。
