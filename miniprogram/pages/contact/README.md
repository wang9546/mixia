# 联系客服模块 (Contact Module)

## 模块简介
提供用户与商家进行沟通的桥梁与线下指引。

## 主要功能
- **门店信息展示**：展示线下门店详细地址、地图导航指引、营业时间等。
- **联系方式**：提供一键拨打商家电话的功能。
- **在线客服**：集成微信官方在线客服组件，方便用户直接在小程序内发起咨询。

## 目录结构
- `index.wxml / contact.wxml`: 页面结构
- `index.wxss / contact.wxss`: 页面样式
- `index.js / contact.js`: 页面逻辑
- `index.json / contact.json`: 页面配置
