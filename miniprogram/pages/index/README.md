# 首页模块 (Index Module)

## 模块简介
首页是小程序的核心入口，采用高级定制（Editorial/Luxury）的设计美学，提供业务的全局导览与优质内容推荐。

## 主要功能
1. **Banner 轮播展示**：展示核心活动或最美客片，带有优雅的底部渐变遮罩。
2. **快捷导航**：提供核心四大业务模块的快速入口（婚纱摄影、现场布置、婚车租赁、四大金刚），采用毛玻璃悬浮卡片设计。
3. **精选案例推荐**：通过杂志化排版，展示各个模块中的精选案例与套餐，吸引用户点击探索。

## 目录结构
- `index.wxml`: 页面结构
- `index.wxss`: 页面样式（高定风格、毛玻璃效果等）
- `index.js`: 页面逻辑（拉取 `getHomeData` 云函数等）
- `index.json`: 页面配置
