# 个人中心模块 (User Module)

## 模块简介
用户的个人专属空间，用于管理个人信息与小程序内的交互数据。

## 主要功能
- **用户信息展示**：展示用户微信头像与昵称。
- **订单与意向管理**：查看已预约或感兴趣的服务项目记录。
- **收藏与足迹**：记录用户浏览过或收藏的婚纱、布置等案例。
- **客服与设置**：提供联系客服、授权设置等功能入口。

## 目录结构
- `index.wxml / user.wxml`: 页面结构
- `index.wxss / user.wxss`: 页面样式
- `index.js / user.js`: 页面逻辑
- `index.json / user.json`: 页面配置
